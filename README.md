# ZenLog

An AI-powered minimalist daily journal and progress tracker.

## Overview
ZenLog pairs structured daily tracking with continuous AI-driven feedback. It captures nutrition, workouts, hydration, habits, and reflections through effortless natural language logging and evaluates your daily pace in real-time.

## Features
- **Pace-Aware Tracking**: Live tracking of protein, water, and activity goals throughout the day.
- **Natural Language Logging**: Log meals, workouts, and thoughts in plain text; AI extracts key metrics automatically.
- **Coaching Verdicts**: On-demand and end-of-day AI reviews powered by Google Gemini.
- **Ink & Paper Design**: High-contrast, clean typography and responsive light/dark themes.

## Architecture
- **Backend**: FastAPI, MongoDB (Motor/PyMongo), Google Gemini API
- **Mobile App**: Flutter (Dart) targeting Android, iOS, and Web
